## 🌿 About The Project

**AYYAN SNACKS SPOT** is a modern website created for a traditional South Indian
snack shop serving authentic and wholesome food.

The website combines a **premium modern interface** with the warmth of
traditional South Indian food culture.

> 🍘 Traditional Taste  
> 🌿 Freshly Prepared  
> ❤️ Healthy Choices  
> 🕰️ Since 2000

## 🔥 Customer Query Architecture

The website uses a simple automated customer-query workflow:

```text
┌──────────────────────┐
│     Customer         │
│                      │
│ Name                 │
│ Contact Number       │
│ Email                │
│ Message              │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   AYYAN Website       │
│      React + Vite     │
└──────────┬───────────┘
           │
           ├───────────────────────┐
           ▼                       ▼
┌──────────────────┐     ┌──────────────────┐
│ Firebase         │     │ Make Webhook     │
│ Firestore        │     │ Automation       │
│                  │     │                  │
│ customer_queries │     │ Receives Query   │
└──────────────────┘     └────────┬─────────┘
                                  │
                                  ▼
                         ┌──────────────────┐
                         │ Gmail            │
                         │                  │
                         │ Confirmation     │
                         │ Email             │
                         └──────────────────┘
